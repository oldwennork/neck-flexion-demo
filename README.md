# Neck Flexion Demo

วัดมุมก้มศีรษะแบบ real-time ผ่านเว็บแคม ด้วย MediaPipe Face + Pose Landmarker
ประมวลผลในเบราว์เซอร์ทั้งหมด — **ไม่มีการส่งภาพออกนอกเครื่อง**

**เปิดใช้งาน:** <https://oldwennork.github.io/neck-flexion-demo/>

## วิธีใช้

1. ใส่ชื่อเล่นแล้วกด **เริ่มใช้งาน** (admin กด "ทดสอบระบบ" + ใส่รหัส → บันทึกในเครื่องแทน)
2. กด **เปิดกล้อง** แล้วอนุญาตการใช้กล้อง
3. ขยับให้ป้ายล่างขึ้น "ระยะกำลังดี" แล้วนั่งคอตรง
4. กด **ตั้ง Baseline** แล้วปล่อยมือจากเมาส์ — ระบบนับถอยหลัง 3 วินาที
5. ก้มลงทีละขั้น และ**ค้างไว้**ที่ทุกๆ 5° (5 / 10 / 15 / 20 / 25°) จนวงแหวนเต็ม
6. กด **บันทึกลง Drive** (ไม่กด = ไม่บันทึก) ไฟล์ชื่อ `ชื่อเล่น_วันที่_เวลา.csv`
   — คอลัมน์ A = เวลา (วินาที), คอลัมน์ B = มุมที่ก้ม (องศา)

## รันในเครื่อง

เบราว์เซอร์จะบล็อกกล้องถ้าเปิดไฟล์ตรงๆ (`file://`) ให้รันเซิร์ฟเวอร์ก่อน:

```bash
python3 -m http.server 8000
```

แล้วเปิด <http://localhost:8000>

## ข้อจำกัด

ค่าที่วัดคือ **มุมก้มของศีรษะเทียบกับกล้อง** ไม่ใช่ craniovertebral angle (CVA) จริง
ซึ่งต้องถ่ายจากด้านข้าง — Pose Landmarker ใช้เฝ้าไหล่เพื่อจับการขยับลำตัวระหว่างวัดเท่านั้น
