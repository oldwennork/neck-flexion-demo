วัดมุมก้มคอผ่านกล้องหน้า

ระบบไม่ส่งภาพจากกล้องออกจากเครื่อง ผลการวัด (ตัวเลขมุม) จะถูกบันทึกลง Google Drive ของทีมวิจัยพร้อมชื่อเล่นที่กรอก

วิธีใช้

  1. ตั้งโทรศัพท์ให้นิ่ง (ขาตั้ง หรือพิงของบนโต๊ะ) ให้กล้องหน้าอยู่ระดับใบหน้า ห่างประมาณ 1 ช่วงแขน — อย่าถือไว้ในมือระหว่างวัด
  2. กด “เปิดกล้อง” แล้วจัดหน้าให้อยู่ในวงรี จนป้ายล่างขึ้น “ระยะกำลังดี”
  3. กด “ตั้ง Baseline” แล้ววางมือลง นั่งคอตรงนิ่งๆ ระบบนับ 3-2-1
  4. ค่อยๆ ก้มลงทีละจุด 5° → 25° ดูหมุดที่แถบใต้ภาพ แล้วค้างไว้แต่ละจุดจนวงแหวนเต็ม — มีเสียงติ๊กระหว่างค้าง และเสียง “ติ๊ง” เมื่อผ่าน ไม่ต้องคอยมองจอ
  5. จบแล้วกด “บันทึกลง Drive” (ไม่กด = ไม่บันทึก)

กล้องไม่ขึ้น? ถ้าเปิดลิงก์จาก LINE / Facebook ให้กด ⋯ แล้ว “เปิดในเบราว์เซอร์” หรือเปิดสิทธิ์กล้องของเว็บนี้ในการตั้งค่าเบราว์เซอร์ แล้วรีเฟรช

วิธีใช้ และข้อจำกัดที่ต้องรู้

ก่อนเริ่ม: ตั้งโทรศัพท์ไว้ให้นิ่ง (ขาตั้ง หรือพิงของบนโต๊ะ) ให้กล้องหน้าอยู่ระดับใบหน้า ห่างประมาณ 1 ช่วงแขน — อย่าถือโทรศัพท์ไว้ในมือระหว่างวัด เพราะมุมที่วัดเทียบกับกล้อง ถ้าโทรศัพท์เอียงตาม ค่าที่ได้จะเพี้ยน

ขั้นตอน: กดเปิดกล้อง → ขยับตัวให้ใบหน้าอยู่ในวงรีและป้ายล่างขึ้น “ระยะกำลังดี” → กด “ตั้ง Baseline” แล้ววางมือลง นั่งคอตรงนิ่งๆ ระบบนับถอยหลัง 3 วิ แล้วเก็บท่านี้เป็นศูนย์ → ค่อยๆ ก้มลงทีละจุด (5° 10° 15° 20° 25° ที่แถบใต้ภาพ) แล้วค้างไว้แต่ละจุด ~2 วิ — มีเสียงติ๊กระหว่างค้าง และเสียง “ติ๊ง” เมื่อผ่านแต่ละจุด ไม่ต้องคอยมองจอ (ปิดเสียงได้ที่ปุ่มลำโพงมุมบน) → กด “จบการวัด” เมื่อไหร่ก็ได้ แล้วกด “บันทึกลง Drive” (ไม่กด = ไม่บันทึก) — โหมดทดสอบของ admin จะดาวน์โหลดไฟล์ไว้ในเครื่องแทน

ข้อจำกัดที่ต้องรู้: ค่าที่วัดคือ มุมก้มของศีรษะเทียบกล้อง ไม่ใช่ craniovertebral angle จริง (CVA ต้องถ่ายจากด้านข้าง) Pose Landmarker ที่เพิ่มเข้ามาใช้เฝ้าไหล่เพื่อจับว่าผู้ทดสอบขยับลำตัว หรือเอนเข้า-ออกระหว่างวัดหรือไม่ ไม่ได้ใช้คำนวณ CVA — ถ้าต้องการ CVA ให้ตั้งกล้องที่สองด้านข้าง 90°

ถ้ากล้องไม่ขึ้น: ถ้าเปิดลิงก์จากในแอป LINE / Facebook / Messenger ให้กดเมนู ⋯ แล้วเลือก “เปิดในเบราว์เซอร์” (Safari หรือ Chrome) — ถ้าเคยกดไม่อนุญาตกล้องไปแล้ว ให้เปิดสิทธิ์กล้องของเว็บนี้ ในการตั้งค่าของเบราว์เซอร์ แล้วรีเฟรชหน้า
